# 第七篇：系統化——讓你的教學專業自動運轉

## 一人公司老師最大的痛

你已經有了產品、有了客戶、有了收入——

但你開始發現一個問題：

- 你要備課、還要寫教案包
- 你要回訊息、還要想下一堂講座的主題
- 你要出考卷、還要整理給機構的課程包
- 你回家只想躺平，但還有一堆一人公司的事情沒做

**一人公司不是工作量加倍——是工作量加倍而且沒有人幫你分擔。**

遲早有一天，你會 burnout。

系統化要解決的問題很簡單：

> **不是你會做多少事情，而是你把多少事情變成不用你親自做。**

---

## 系統化的三層次（國小科技教師版）

### 🛠️ 第一層：工具自動化（取代你的勞力）

把重複性高、不需要腦袋的事情交給工具：

- 📅 **排程**：Calendly / SimplyBook.me——讓家長或機構自己約時間，不用來回喬
- 💰 **金流**：LINE Pay / 綠界 / Stripe——自動收款、自動開發票
- 📧 **聯絡**：電子報自動發送（寫一次排程就好）
- 🤖 **AI助手**：ChatGPT / Claude幫你回覆常見QA、整理教學筆記、擬合約草稿

**你的目標：所有不用你「親自想」的事情，都讓工具做。**

### 📋 第二層：流程標準化（取代你的判斷）

比較複雜的事情，不是不能交給工具，而是要先**把步驟寫下來**。

**備課流程標準化：**
- 建立你的教案模板，一份教案用同一個格式
- 學習單用 Canva / Word 模板，每次改主題就好
- 評量方式固定幾種（實作評量、觀察記錄、學習檔案）
- 備一堂課的時間從 2 小時降到 30 分鐘

**客戶諮詢流程標準化：**
1. 對方私訊你 → Google Form 收集需求與預算
2. 按照 SOP 判斷要不要接、開多少錢
3. 要接 → 合約模板改名字就寄出
4. 結案 → 自動請款、開發票、歸檔

**內容產出流程標準化：**
- Notion 開一個頁面叫做「內容點子庫」
- 上課想到什麼就記在手機備忘錄
- 週末一次整理，變成貼文、影片、指南

### 🧠 第三層：知識系統化（取代你的記憶）

這是最有累積價值的一件事。用任何筆記工具（Notion / Heptabase / Obsidian）建立你的教學知識庫：

```
📂 我的教學知識庫
├── 📁 教案資料（單元分類）
├── 📁 工具評測（用過的科技工具，寫下優缺點）
├── 📁 學生常見問題（哪些概念小孩最容易卡住）
├── 📁 家長常問問題（統一回覆模板）
├── 📁 教學故事（值得記錄的瞬間）
└── 📁 一人公司營運（產品、定價、合作洽談記錄）
```

**一年之後，你會有自己專屬的百科全書——那是你一個人比不上一家公司的時候，最強的護城河。**

## 一個實際的客戶流程表格

| 階段 | 你做的事 | 可以怎麼系統化 |
|:----|:--------|:-------------|
| 客戶詢問 | 來回私訊確認需求、報價 | 做一個 **「常見問題」頁面** + **報價模板** |
| 簽約 | 自己擬合約、改來改去 | 用 **合約模板** + **電子簽章** |
| 執行 | 你自己教課 | **這部分留著**（這就是你的價值） |
| 結案 | 請款、開發票 | **自動請款系統** + **雲端發票** |
| 售後 | 客戶問問題你回答 | **QA 知識庫**，類似的問題貼連結就好 |

看出來了嗎？**只有中間的「執行」是你需要親自做的——前後都有辦法用系統取代。**

---

## 哪些事情應該外包？

一人公司不是什麼都要自己做。你的時薪如果值500元，那就把時薪300元能做的事情外包出去。

| 你該自己做的（核心） | 可以外包的（省時間） |
|:------------------|:-------------------|
| 教案設計 | 排版美化（學習單給美編整理） |
| 課程內容 | 簡報設計（你寫內容，設計師幫你做PPT） |
| 課堂教學 | 記帳報稅（記帳士，一個月1500元） |
| 與家長溝通 | 網站架設（Wix/WordPress外包一次搞定） |
| 你的專業品牌 | 影片剪輯（錄好之後找人剪） |

---

## 一個可以馬上開始的系統化

| 這週做什麼 | 下個月做什麼 | 三個月後做什麼 |
|:---------|:----------|:------------|
| 建立一個教案模板（用你原來最順手的格式） | 建好你的內容點子庫 | 把教案包變成一個可以自動發送的數位商品 |
| 把教案統一放在一個資料夾（不要散落在電腦各處） | 規劃你的 SOP 流程 | 把自己的時間從接案中解放出來做更有價值的事情 |

---

## 系統化後的你

- 客戶覺得你很專業（因為回覆快、流程順）
- 你覺得自己很輕鬆（因為大部分事情自動在跑）
- 你有時間開發新產品、學新東西、甚至休假

**一人公司最大的目標，不是做到死。是用最少的時間、最穩定的品質，把錢賺到。**
