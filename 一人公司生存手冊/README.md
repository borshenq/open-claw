## 快速摘要

### 起點
你已經是國小科技教師，有教學專業，但學校的薪水有天花板。一人公司不是叫你辭職，是讓你把已經會的專業，拿去幫體制外需要你的人。

### 你可以賣什麼
1. **賣給老師**：教案包、學習單模板（單價低走量）
2. **賣給家長**：講座、電子書、諮詢（付費意願高）
3. **賣給機構**：課程包授權、師資培訓（單價高）
4. **賣給平台**：Hahow/Udemy 線上課程（被動收入）

### 最低啟動方式
寫一篇貼文：「我是一個國小科技教師，這是我的學生現在在學什麼。」發在 Facebook 或 Threads——先看市場反應，再決定下一步。

### 關鍵提醒
- 正職優先，一人公司是加分不是取代
- 週六兩小時產出，比每天熬夜有效
- 三層收入：主動（接案）→ 被動（課程）→ 槓桿（分潤）
- 存下收入的 20%，永遠不動
- 健康是第一生產設備，不能省
